# Ocharo Studio — Features

*Last updated: 2026-09-28*

The detailed first-release contract is in `studio.md`.

| Capability | First release | Notes |
|---|---|---|
| 3D garment presentation | Yes | Fixed silhouette mannequin and authored single-size garments. |
| Garment selection | Yes | One-click selection, beginning with a complete nimcha workflow. |
| Per-part material editing | Yes | Part lists belong to each garment type. |
| Texture placement | Yes | Individual rotation/anchors; grouped scale and garment-relative offsets. |
| Built-in attachments | Yes | Garment-authored buttons, ties, and knots load automatically. |
| Inspection | Yes | Animated presets, trackpad orbit, common full-height framing. |
| Creative history | Yes | Undo and redo for meaningful edits. |
| Editable saved looks | Yes | Save, list, reopen, rename, and continue editing. |
| Portable design export | Yes | Versioned JSON that preserves asset references and edits. |
| Presentation export | Yes | Clean silhouette PNG, and Studio render: print-size PNGs on the silhouette or the model. |
| Responsive controls | Default | Laptop/tablet/phone islands and accessible contextual walkthrough. |
| Decorative overlays | Future | No first-release commitment. |
| Size and length controls | Future | Require deliberately authored asset support. |
| Construction, CAD, pricing, ordering | Excluded | Outside the product promise. |

## Content families

The initial content model supports `nimcha`, `baska`, `kostyum`, `korset`, and `abaya`. Supporting a family means delivering usable authored assets and declared editable parts, not merely showing its name in the interface.
