# Iteration guide

*Last updated: 2026-09-25*

Implement one complete user workflow at a time, verify behaviour, and update the planning record.
The first target is garment selection through part editing to save/reopen, with a single nimcha asset.
Use meaningful state-isolation and persistence tests plus visual verification of the actual 3D scene.
Only completed, verified cohesive batches qualify for the user's subsequent local auto-commit authorization.
